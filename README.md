# Secure Employee Management System

## Overview
A Java and MySQL application developed as part of a Software Development team project. The system allows HR administrators and employees to securely manage employee information through role-based access control.

## Features
- User authentication
- Role-Based Access Control (RBAC)
- Employee CRUD operations
- Payroll reporting
- Employee search
- MySQL database
- UML design documentation

## Technologies
- Java
- MySQL
- JDBC
- SQL
- UML
